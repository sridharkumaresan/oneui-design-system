# @functions-oneui/onboarding-styles

Token-driven CSS and visual helpers for OneUI onboarding experiences.

## Purpose

- Provide a reusable stylesheet for Driver.js-based walkthroughs
- Keep styling aligned with Fluent-first OneUI tokens
- Support non-React consumers through CSS and variable helpers

## Public API

- `@functions-oneui/onboarding-styles/styles.css`
- `createOneUIOnboardingCssVariables(...)`
- `createOneUIOnboardingVariableStylesheet(...)`

## Usage

```ts
import "@functions-oneui/onboarding-styles/styles.css";
import { createOneUIOnboardingVariableStylesheet } from "@functions-oneui/onboarding-styles";
```
